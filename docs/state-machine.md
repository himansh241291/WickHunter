# WickHunter State Machine

WickHunter is a long-only finite-state machine.

```text
DAY_START
   |
   v
LEVELS_READY
   |
   v
WAIT_FOR_LOW_SWEEP
   |
   v
WAIT_FOR_BULLISH_SIGNAL
   |
   v
LONG_READY
   |
   v
LONG_ENTRY
   |
   v
POSITION_OPEN
   |
   +----> TAKE_PROFIT
   |
   +----> STOP_LOSS
   |
   v
DAY_COMPLETE / WAIT_FOR_NEXT_SETUP
```

## Hard invariants

1. Only long positions may be opened.
2. No SELL order may be generated by strategy logic.
3. No short-position state exists.
4. A failed setup must expire deterministically.
5. A consumed sweep must not create unlimited duplicate entries.
6. Risk controls may prevent an otherwise valid long entry.
